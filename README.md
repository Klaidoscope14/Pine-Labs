# AegisSDLC

Governed multi-agent software delivery for fintech. Agents propose, gates prove, humans decide.
The full plan is in [PLAN.md](PLAN.md). The build schedule is in §10.

## Phase 0: run it

Requirements: Go 1.25+, Docker with BuildKit, GNU Make, `openssl`, `curl`.

```bash
make phase0
```

That runs every Phase 0 exit check in order:

| Target | Proves |
|---|---|
| `make test` | Config guard and agent contracts (Go unit tests) |
| `make validate-config` | Good config passes; every bad fixture is rejected |
| `make sandbox-image` | Hardened gate-runner image builds with pinned, hash-verified tools |
| `make sample-test` | Sample repo's lint, tests and live smoke test pass in the locked-down sandbox |
| `make hidden-test` | Hidden oracle tests fail on the base code (the planted bug is real) |
| `make sandbox-egress-check` | The sandbox has no network, and every gate tool is present |
| `make up` | Every stack service is healthy, egress is denied, ports bind to 127.0.0.1 only |

`make down` stops the stack. Local secrets are generated by `make secrets` into
`deploy/compose/.env.secrets` and are never committed.

## Layout

| Path | What |
|---|---|
| `cmd/aegis-api` | API server (Phase 0: config guard + health) |
| `cmd/aegis-config` | Validate config; print derived sandbox flags |
| `internal/config` | Config loading, schema validation, jurisdiction guard |
| `internal/contracts` | Agent output validation against JSON Schemas |
| `internal/sandbox` | Hardened `docker run` flags (from config) |
| `schemas/` | Config schema and agent contracts, with examples |
| `sandbox/` | Gate-runner image |
| `deploy/compose/` | Local stack; every version in `versions.env` |
| `samples/pine-settlements-svc` | Demo target service with the planted duplicate-webhook bug |
| `evals/hidden/` | Hidden oracle tests (never mounted for agents, never in images) |

Configuration: `config.example.yaml` documents every setting with placeholders.
`config.local.yaml` is for local development.
