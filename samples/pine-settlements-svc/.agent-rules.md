# Rules for coding agents in this repo

- Money is integer paise. Percentages use `Decimal` with an explicit rounding mode. Never `float`.
- Every state-changing payment or webhook endpoint must be idempotent.
- Webhook signatures are checked with `hmac.compare_digest`. Never remove or weaken the check.
- Never log card numbers, CVV, Aadhaar numbers, tokens or secrets.
- Use parameterised SQL only.
- Do not edit, skip or delete existing tests. Add new tests instead.
- Do not add new dependencies. Ask a human.
- Files listed in `protected_paths.yaml` are off-limits.
